Roman Urdu Leaderboard

How well do AI models read, write and understand Roman Urdu, the way most Pakistanis type? Every test item comes from text written or romanized by people. Scores run from 0 to 100; higher is better.

The tasks

Transliteration (300 sentences)
Roman Urdu to Urdu script. Urdu Wikipedia sentences romanized by native speakers (Google's Dakshina set). Score is 100 minus the character error rate, after removing diacritics and unifying letter variants.
Reading (300 questions)
Multiple choice on Roman Urdu passages (Meta's Belebele, romanized by annotators). Accuracy.
Translation (120 passages)
Roman Urdu into English, scored with chrF++ against the original English (FLORES). Shown, but not counted in Overall: one model reproduced 45 of the 120 English references almost word for word, which points to the text being in its training data.
Sentiment (300 comments)
Real Roman Urdu social-media comments, 100 each positive, negative and neutral (UCI Roman Urdu dataset). Macro F1. The source labels are noisy, so no model gets near 100.

How models were run

Every model sees the same instructions. Models with an API run one item at a time at temperature 0. Models only available through a chat app (ChatGPT, claude.ai) got the same items in numbered batches of 15 to 50, each batch in a fresh temporary chat. Open models ran locally through Ollama at 4-bit. The highlighted row is our own 1.5B model, fine-tuned for transliteration only on Dakshina sentences that are not in the test set.
